# Phishing Email Investigation Lab

## Project Overview
This project demonstrates a basic SOC Level 1 phishing email investigation using a simulated phishing email.

The aim is to identify suspicious email characteristics, examine potential indicators of compromise (IOCs), assess the risk, and document recommended security actions.

## Investigation Scenario
A fictional employee receives an email claiming that their Microsoft 365 account will be suspended unless they verify their account details.

The email is treated as suspicious and investigated as part of a simulated security exercise.

## Objectives
- Identify common phishing indicators.
- Examine sender details and suspicious links.
- Record potential indicators of compromise.
- Assess the potential risk to the organisation.
- Document findings and recommended actions.

## Tools
- GitHub – project documentation
- Email header and content analysis
- VirusTotal – reputation checking, where appropriate

## Disclaimer
This is a simulated investigation using fictional information. No real employee accounts, credentials, or malicious emails are involved.
